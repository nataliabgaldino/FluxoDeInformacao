Desenvolvimento de um documento avaliativo de uso de TI em etapas de Fluxo de Informação para o processo de suporte técnico a um computador. 
O projeto foi iniciado pela análise do processo de suporte técnico a um computador, elaboração do fluxo de informação do processo, depois pelo mapeamento das etapas do fluxo e por fim, levantamento das tecnologias 
e indicação de sistema de informação.
